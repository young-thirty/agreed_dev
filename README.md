# Agreed

고객 메시지가 들어오면 계약·과거 대화·티켓·GitHub 개발 상황을 확인해 요구를 분석하고, 바로 보낼 수 있는 답변 초안까지 만들어 줍니다. 티켓 생성과 상태, 최종 발송은 사람이 정합니다.

## 시작

```bash
pnpm install
pnpm dev
```

http://localhost:3000

지금은 백엔드 없이 목 데이터로 도는 프로토타입입니다. 분석 결과와 GitHub 개발 현황은 `mocks/index.ts`에 있고, 사람이 내린 판단만 localStorage에 남습니다. 사이드바의 **처음부터 다시**로 언제든 초기 상태로 돌아갑니다.

## 화면

| 경로 | 내용 |
|---|---|
| `/tickets` | 티켓 목록 (처리 필요 · 전체 · Active · Done · Reject). 새 고객 메시지는 관련 티켓에 붙고, 없으면 Active 티켓으로 새로 들어온다 |
| `/tickets/[id]` | 고객 메시지 → AI 분석 → 내 판단 → 답변 초안 + 이 티켓의 지난 대화 |
| `/projects` | 프로젝트 목록 |
| `/projects/[id]` | 티켓 · 고객 메시지 · 프로젝트 컨텍스트 |
